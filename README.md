# 📚 StudyHub

**StudyHub** is a mobile application designed to help students study, collaborate, and track their academic progress in one place.

## 🚀 Features

* 🎥 **Study Together** — Connect with other students studying the same subjects.
* 📚 **Study Resources** — Access learning materials, unit-wise resources, previous-year questions, and useful YouTube links.
* ⏱️ **Study Timer** — Track focused study sessions using an integrated timer.
* 🔥 **Study Streaks** — Maintain daily study streaks and stay consistent.
* 📊 **Progress Tracking** — Monitor your study progress and maintain better study habits.
* 👥 **Student Collaboration** — Create a more interactive environment for students to learn together.

## 🛠️ Tech Stack

* **Frontend:** React Native / Expo
* **Backend:** Firebase
* **Database:** Firebase
* **Authentication:** Firebase Authentication
* **Design:** Figma

## ⚙️ Getting Started

### Prerequisites

Make sure you have:

* Node.js
* npm
* Expo CLI
* Android Studio or Expo Go

### Installation

Clone the repository:

```bash
git clone https://github.com/HariniRJ/studyhub.git
```

Navigate to the project:

```bash
cd studyhub
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npx expo start
```

Then scan the QR code using **Expo Go** or run the application using an Android emulator.

## 🎯 Project Goal

The goal of StudyHub is to provide students with a single platform for **collaborative learning, study resources, focused study sessions, and progress tracking**.
